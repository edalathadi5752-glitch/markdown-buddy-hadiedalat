# Reflection Questions

## 1. How did AI help you create project documentation?

AI helped me organize project information into a professional documentation structure. It provided suggestions for README sections, formatting, and R Markdown organization.

## 2. What limitations did you observe when using AI?

Some generated content was generic and required editing to better match my project. Manual verification was necessary to ensure accuracy.

## 3. How did you verify and improve AI-generated content?

I reviewed all generated content, checked Markdown formatting using GitHub preview, and compared the structure with examples from GitHub repositories. I made revisions to improve clarity and accuracy.
